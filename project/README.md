# MWS GPT Hub — Единое AI-рабочее пространство

## Что это?
Расширенный OpenWebUI с умной маршрутизацией запросов к MWS GPT API.
Одно окно чата — все AI-возможности.

---

## Как запустить (однострочный запуск)

```bash
docker compose up --build
```

После запуска открыть в браузере: **http://localhost:3000**

---

## Пошаговая инструкция

### 1. Установить зависимости
- [Docker Desktop](https://www.docker.com/products/docker-desktop/) (включает docker compose)

### 2. Скачать проект
```bash
git clone <ваш-репозиторий>
cd project
```

### 3. Настроить ключи
```bash
cp .env.example .env
```
Заполните в `.env` ключ MWS GPT API и секрет OpenWebUI. Файл `.env` в репозиторий не попадает.

### 3a. Запустить
```bash
docker compose up --build
```

Первый запуск занимает ~3-5 минут (скачиваются образы).

### 4. Открыть интерфейс
Перейти на http://localhost:3000

### 5. Зарегистрироваться
Создать аккаунт (первый пользователь становится администратором).

## Что умеет система

| Возможность | Как использовать |
|---|---|
| Текстовый чат | Просто пишите |
| Умный выбор модели | Автоматически по типу запроса |
| Ручной выбор модели | Выбор из списка в интерфейсе |
| Долгосрочная память | Автоматически — факты о вас сохраняются |
| Парсинг ссылок | Вставьте URL в сообщение |
| Веб-поиск | Напишите "найди в интернете..." |
| Загрузка файлов | Кнопка прикрепления файла в чате |
| Код | Задачи по коду → автоматически kodify-2.0 |

---

## Модели и когда выбираются

| Запрос | Модель |
|---|---|
| Обычный текст | mws-gpt-alpha |
| Код / программирование | kodify-2.0 |
| Длинные документы | cotype-preview-32k |
| Семантический поиск | bge-m3 |

---

## Архитектура

```
Пользователь
    ↓
OpenWebUI (порт 3000) — фронтенд чата
    ↓
FastAPI Backend (порт 8000) — роутер + память + инструменты
    ↓
MWS GPT API (api.gpt.mws.ru)
```
